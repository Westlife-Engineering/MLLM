# ViT 精读

An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale，ICLR 2021。

不必先读论文。下面按「问题 → 做法 → 结果 → 能拿走什么」写。需要看图时，打开 PDF 只看那一张。层数、学习率和每张表的原始数字留在论文里，正文会告诉你去哪一节核对。

## 先看这四段

**这篇论文解决了什么问题。** 当时把注意力用在认图上，要么接在卷积网络后面，要么把注意力改成只看邻域、只看某一行某一列，以便能在硬件上跑。这篇问的是：几乎不改语言模型里那套 Transformer，把一张图切成小块当词送进去，再在很大的有标签数据上做分类预训练，能不能在中小规模的认图考试上追上当时的大卷积网络，而且预训练更省计算。

**作者用了什么方法。** 图切成固定大小的方块，每块线性变成一个向量，序列最前面加一个可学习的分类 token，每个位置再加一个可学习的位置向量，送进标准 Transformer。预训练时，分类 token 的最终状态经过一个只有一个隐藏层的多层感知机，去预测预训练数据里的类别。换下游数据集时，这颗头整个丢掉，换成一个新的线性层；分辨率如果提高，按二维网格把位置向量插值放大，然后整个网络继续训练。

**实验说明了什么。** 预训练数据大到 JFT-300M 这一档时，最大的 ViT 在多个认图基准上追上或超过当时的大卷积迁移模型，预训练计算更少。数据停在 ImageNet 时，大 ViT 反而不如小 ViT，也不如卷积网络。遮住图块再预测颜色的自监督有一点帮助，仍明显落后于大规模有监督预训练。

**能学到什么。** 可以拿走的判断是：模型里少写「局部、平移后规律不变」这类假设时，用数据规模去补，前提是数据大到让大模型压过小模型。分类头可以丢掉，预训练留下来的是编码器。位置不够用时，按网格把已有的位置向量平滑放大。

## 研究问题

**背景。** 这篇之前，认图的稳定做法是卷积网络。把卷积做大，放到 ImageNet-21k（约 1400 万张、2.1 万类）或 JFT-300M（约 3.03 亿张、1.8 万类）上预训练，再迁移到较小的考试上，已经是成熟路线。语言模型则是另一套用法：先在大语料上预训练 Transformer，再在小任务上微调，模型可以一直做大。

**痛点。** 把标准自注意力原样用到像素上，每个像素都要看所有像素，计算量随像素数平方增长，正常分辨率的图吃不消。改成局部或按轴的注意力之后，理论上省了，但这些特制模式没有在当时的加速器上放大到最大规模的认图。于是大规模认图仍然是卷积。Transformer 自己又缺卷积那种每层都有的局部性和平移等变性，数据不够时泛化差。坏掉的地方不在某一个卷积层，而在「序列太长」和「结构假设太少、数据却没大到能补上」这两处。

**本文要解决的问题。** 在尽量少加入视觉专用结构的约束下，把一张图变成一条图块序列，用标准 Transformer 做有监督分类预训练，再迁移到 ImageNet、CIFAR、VTAB 这类数据更少的认图任务上，看成绩能不能追上当时的大卷积网络，并且预训练计算更少。

**为什么值得做。** 若做成，认图可以沿用语言模型里已经跑顺的 Transformer 实现，不必再为视觉单做一种注意力。预训练一次，换掉最后的分类头，就能接到多个中小数据集上。

**一句话。** 这篇论文在研究：少写视觉专用结构时，图块序列上的标准 Transformer 加上大规模有监督预训练，能否在下游认图上达到大卷积网络的迁移成绩。

**以前怎么做、缺在哪。**

卷积加大、放到 ImageNet-21k 或 JFT 上再迁移，当时已经能在这些考试上拿到最好的一档成绩。缺的是同一种数据规模下，标准 Transformer 有没有被测过。

视觉里的注意力已经能用：接在卷积特征后面，或者用邻域、按轴、稀疏的注意力替换卷积。缺的是放大。论文的批评是，特制注意力模式在加速器上不好扩展，所以大规模认图仍是类 ResNet 的结构。

有人已经把图切成 2×2 的小块再做全局注意力，和这里很像。缺的是尺度：块太小，只适用于低分辨率，也还没有把大规模预训练做完。

把图降采样、缩小颜色数之后，用 Transformer 做生成式预训练再拿去分类，ImageNet 上大约 72%。缺的是和当时有监督大卷积之间的那一截，以及它走的是生成，不是这篇的分类预训练。

## 方法

**直觉。** 它改的决定是：不再给每一层写上「只看邻近像素」。图先切成块，块当词，空间关系交给数据去学。卷积的结构假设只留在两个很窄的地方：开头怎么切块，以及微调时怎么把位置向量网格放大。

**方法是什么。** 模型叫 Vision Transformer（ViT）。相对上面几条旧路线，它换掉的是卷积主干和特制注意力，换成语言模型里的标准 Transformer 编码器。预训练目标是有监督分类，不是遮词，也不是生成像素。另一个他们同时训练的变体是混合模型：前面仍用卷积抽出特征图，再把特征图切块送进同一个 Transformer。混合模型的训练设置和对应的纯 ViT 相同。

**步骤。**

1. 切块并投影。输入是一张图。按固定边长 \(P\) 切成 \(N\) 块，每块拉直，乘一个可学习的矩阵，变成 \(D\) 维向量。解开的是「图不是一条词序列」。
2. 接上分类 token，加上位置向量。序列最前面拼一个可学习向量，再给每一个位置（含分类 token）加上该位置自己的可学习向量。输出长度是 \(N+1\)。解开的是「整张图要有一个汇合处，而且块的位置不能丢」。位置向量在初始化时不带二维坐标，行列关系是后来学出来的。
3. 过编码器。每一层先做多头自注意力，再做前馈网络，都是先 LayerNorm、再残差加回去。输出仍是同样长度的序列。解开的是「块和块之间怎么交换信息」。注意力是全局的，前馈网络才作用在每个位置自己身上。
4. 用分类 token 做预训练。取这个 token 在最后一层的状态，做一次 LayerNorm，得到图像向量 \(y\)。预训练的分类头是一个只有一个隐藏层的多层感知机，隐藏层用 tanh，把 \(y\) 变成预训练类别数那么多个分数。解开的是「在大标签集上把编码器训成能区分很多类的特征」。优化用 Adam，batch 4096，学习率先升温再衰减。数据大时少正则、轮数少；数据只有 ImageNet 时加强 weight decay 和 dropout，并训更久。系数、轮数在 Appendix Table 3，不要在这里背。
5. 换数据集时换头、必要时放大位置网格，然后整网微调。旧头的输出维数等于旧的类别数，新数据集类别不同，整颗头丢掉，换成一个权重为 0 的线性层，输出维数等于新的类别数。分辨率提高时图块大小不变，序列变长，按位置向量在原图上的二维位置做插值。然后整个编码器连同新头一起更新，优化器改成带动量的 SGD。解开的是「新的类别名单，以及更密的网格」。微调的学习率范围和步数在 Appendix Table 4。

论文还报告：整颗头换掉，比只重初始化最后一层更稳（Appendix B.1.1）。【推断】留着的隐藏层是为旧的那一万多个类学的，接到新名单上容易带偏。依据只是「更稳」这个实验结果，论文没有解释原因。

**一个具体例子。** 按 §3.1 和 §3.2 的设定走一张图。输入是 224×224 的图，图块 16×16，于是网格是 \(14\times14\)，一共 196 块。每块投影成 \(D\) 维，前面加上分类 token，变成 197 个向量，各自加上位置向量，送进编码器。最后只读分类 token 对应的 \(y\)。若在 ImageNet-21k 上预训练，分类头把 \(y\) 打成约 2.1 万个类的分数；若在 JFT 上，则是约 1.8 万个类。Figure 1 画的就是这条路：图块变成序列，分类 token 走向 Bird、Ball、Car 这类名字。

换到 ImageNet（1000 类）时，那颗头扔掉，换成 1000 维的线性层，\(y\) 仍由原来的编码器产生。若微调分辨率改为 384，图块仍是 16×16，网格变成 \(24\times24\)，需要 576 个图像块的位置向量。把已经学好的 \(14\times14\) 位置向量排回格子，平滑放大到 \(24\times24\)：新格点落在旧格点之间时，用邻近旧格点的向量做加权平均，每个维度分开算。分类 token 不在这个网格上。【推断】它的位置向量原样保留，只放大图像块那一块。依据是 §3.2 说的「按它们在原图中的位置」做二维插值。

**和旧方法的差别。** 卷积主干和特制的局部注意力换成了标准编码器。序列单位是图块，不是像素。预训练是分类，不是生成。迁移时换的是最后的读出层，并允许分辨率比预训练更高。混合模型则是把「卷积前端」留了回来，用来对照纯图块是不是够用。

**创新点。** 论文自己声称的贡献有三件：纯 Transformer 直接吃图块就能做分类；数据规模大了之后，可以压过它缺少的结构假设；在多个认图基准上达到或超过当时的卷积网络，预训练计算更少。

【推断】真正新的一点是这个实验结论，而不是图块嵌入或分类 token 这些零件。那些零件在语言模型和更早的小块注意力里已经有了。新的是把「少做视觉专用设计」和「用数据规模代替结构假设」放进同一次比较，并用同一套预训练预算去和卷积比。依据是 Figure 3、Figure 4 和 §4.4。

**数学。** 这些式子不在惩罚某一块像素的误差。它们规定图怎么变成一条向量，以及这条向量怎么更新。类别对错由最后的分类头承担。预训练和微调都是有监督分类，论文没有单列损失公式，用的是标准的分类损失。数据较小时，还会在 weight decay、dropout、label smoothing 里做调节（§4.3），label smoothing 的系数没有写进表。

图块投影、分类 token 和位置向量加在一起，得到编码器的输入。\(E\) 把每个图块从像素映到 \(D\) 维，\(E_{\mathrm{pos}}\) 与这条序列形状相同，逐元素相加：

$$
z_0 = [x_{\mathrm{class}};\, x^1_p E;\, \ldots;\, x^N_p E] + E_{\mathrm{pos}}
$$

这一步控制的是输入里同时有「这块长什么样」和「这块在哪里」。

每一层先混合序列，再在每个位置上做前馈。先 LayerNorm，残差加回原序列。前馈网络是两层，中间用 GELU。它和分类头不是同一段：这里每个 token 都要过，分类头只在最后处理 \(y\)。

$$
z'_\ell = \mathrm{MSA}(\mathrm{LN}(z_{\ell-1})) + z_{\ell-1}, \qquad
z_\ell = \mathrm{MLP}(\mathrm{LN}(z'_\ell)) + z'_\ell
$$

这两式控制的是信息如何在块之间流动，以及每个位置内部如何变换。

整张图的表示只取分类 token 在最后一层的状态，再做一次 LayerNorm：

$$
y = \mathrm{LN}(z^0_L)
$$

这一式控制的是「用哪个向量去分类」。预训练时，一个带 tanh 隐藏层的多层感知机把 \(y\) 变成 \(K\) 个类别分数。微调时，换成一个线性层。没有需要再推的核心公式，到分类损失为止。

## 实验或验证

**数据够大时，ViT 的迁移成绩追上当时的大卷积模型，预训练计算更少。**

- **结论：** 在 JFT-300M 上预训练的最大模型 ViT-H/14，微调后 ImageNet 正确率 88.55%。论文同时给出的预训练计算量低于对照的大卷积模型。
- **看哪里：** Table 2。盯 ImageNet 那一行，以及最下面的 TPUv3-core-days。CIFAR-10 和 Flowers 大家都很满，看不出方法差别。VTAB 那一行才拉开。Figure 2 把 VTAB 拆成三组：Natural 和 Structured 上 ViT 更高，Specialized 上和最强的卷积模型接近。
- **别看错：** 论文写明，预训练效率不只由结构决定，日程、优化器、weight decay 都掺在里面。Table 2 的 core-days 不是严格控制变量的对比。受控对比在 Figure 5。另外，Table 2 的 ImageNet 用了更高分辨率（ViT-L/16 到 512，ViT-H/14 到 518）和权重平均；Table 5 的 ImageNet 没有这两项，数字会低一截。

**数据停在中等规模时，少结构假设会让大 ViT 先坏。**

- **结论：** 只在 ImageNet 上预训练时，大 ViT 不如小 ViT，也落在卷积模型的成绩区间下面。预训练集加大到 JFT 的全量，大小关系才反过来。
- **看哪里：** Figure 3 从左到右三列，看大模型的柱子何时超过小模型，以及何时超过灰色的卷积区间。Figure 4 看 JFT 子集从约 900 万张加到全量时，谁的曲线先抬起来、谁先进入平台。大约 9000 万张之前卷积更好，之后 ViT 更好。
- **别看错：** Figure 3 里「在 ImageNet 上预训练」的模型，仍会再在 ImageNet 上微调，因为微调提高了分辨率。Figure 4 是冻住编码器后的线性 few-shot，不是完整微调；小子集也没有额外加强正则，为的是看模型本身，不把正则的功劳算进去。

**把计算量对齐之后，ViT 仍高于卷积；卷积前端只在模型小的时候有用。**

- **结论：** 同样的预训练计算下，ViT 一般高于 ResNet，达到同一迁移成绩大约少用 2 到 4 倍计算。前面接卷积的混合模型在计算量小的时候略好，模型大了差距消失。
- **看哪里：** Figure 5。横轴是预训练计算量，纵轴是迁移成绩。看大计算量那一端，混合模型和纯 ViT 是否并到一起。
- **别看错：** 混合模型名字末尾的数字是卷积前端的下采样倍数，不是图块边长。

**位置向量会学出二维布局；浅层就已经有头在看整张图。**

- **结论：** 完全不加位置信息会差一截；一维、二维、相对位置这几种写法彼此差不多。浅层里，有的注意力头跨过几乎整张图，有的只看附近；层数变深，跨度变大。
- **看哪里：** Table 8 第一行明显低于后面几行，后面几行挤在一起。Figure 7 中间看亮块是不是沿行、沿列，右边看点随着层数往上走。Figure 6 看从分类 token 滚出来的注意力落在不落在物体上。
- **别看错：** Figure 6 是例子，不是定量证明。位置向量的相似度图案会随学习率、weight decay 和轮数改变，看 Figure 10。分类 token 也不是唯一读出：把所有图块向量做全局平均再分类，把学习率重调之后可以接近，看 Figure 9 和 Appendix D.3。

**遮块预测有帮助，替代不了大规模有监督预训练。**

- **结论：** 较小的 ViT-B/16 用遮块预测预训练后，ImageNet 正确率 79.9%，比从零训练高 2 个点，仍比有监督预训练低 4 个点。
- **看哪里：** §4.6。这是初步实验，不是 Table 2 的训练方式。
- **别看错：** 预测目标是被遮住图块的平均颜色，不是重建像素。做法在 Appendix B.1.2。

要核对预训练和微调的做法，看 §4.1 和 Appendix B.1。

## 能带走什么

**Takeaways。**

1. 预训练数据大过 ImageNet 这一档之后，少写局部性的 Transformer 可以在认图迁移上超过大卷积网络。数据停在 ImageNet 时，卷积的结构假设仍有用，把 ViT 做大只会更差。
2. 预训练要留下来的是编码器。分类头绑在旧的类别名单上，换任务时整颗换掉，新头从零开始，整网再更新。
3. 提高分辨率时图块大小不变，序列变长。位置向量按二维网格插值，新位置仍大致表示「画面的这一带」。这件事成立，是因为训练后靠近的位置向量本来就比较像。
4. 分类 token 是一个方便的汇合处，不是唯一可行的读出。全局平均在学习率重调之后可以接近，条件是你愿意重调学习率。
5. 在这篇的实验里，大规模有监督分类预训练明显强于他们试过的遮块预测。不能把这篇的主结果理解成自监督。

**值得借的思路。** 借的是「少写结构假设」和「把数据规模加大」必须一起测。只换骨干、数据维持原样，测到的会是过拟合，不是这条路线的终点。

**可迁移的部分。** 图块当 token、分类 token 读出、换头微调、位置网格插值，可以拿到别的整图分类上。绑死在本文设定上的是：要有一个很大的有标签分类数据集，任务是整张图一个标签。检测和分割这篇没有做。混合卷积前端只在模型还小的时候值得留。

**实验设计可参考的一点。** 同一套优化设置下比较 ViT 和卷积，再用 JFT 的随机子集把数据量拆开，小子集不额外加正则。这样「结构假设在小数据上有用」和「数据大了之后假设可以少写」分成了两截，不会混成一句「Transformer 更强」。

**论文写明的不足。** 检测和分割还没做，所以这套迁移只覆盖整图分类。自监督和大规模有监督之间仍有明显差距，没有大标签集时不能指望这篇的遮块预测补上。数据不够大时，缺少结构假设会让大模型更差，因此不能把 ViT 直接拿去小数据集上从零训练，当成通用配方。

## 思路重建

下面是重建，不是论文陈述。

当时能观察到的是：语言模型里，Transformer 先在很大的文本上预训练，再在小任务上微调，模型做大之后成绩还没有看到顶。认图这边，最好的结果仍来自卷积，而且卷积也已经放到了千万到亿级的有标签图像上。

现成工具接不上这个观察。标准自注意力若以像素为单位，序列长度就是像素数，计算量平方增长，正常大小的图走不通。把注意力限制在邻域或某一行某一列，计算上能走，但这些特制写法没有在加速器上放大到当时最大的认图设定。语言模型里那套「原样的 Transformer、原样的实现」因此进不了视觉的主流程。

【推断】把设计推到下一步的类比是：词本来就是一个个 token，图不必让每个像素当一个词。先切成一小块，一块当一个词，序列长度从像素数变成块数，标准 Transformer 才有机会原样用上。特殊的局部注意力就可以先不设计。

同时已经知道，卷积能在中等数据上工作，是因为每一层都写死了局部、以及平移之后规律不变。这些一旦拿掉，小数据上变差是可以预期的。因此值得试的方向是：少改结构，把规模放到数据和模型上，看结构假设会不会被数据盖过。终点停在这个方向，后面的分类头、插值和具体考试是试了之后才定下来的。
