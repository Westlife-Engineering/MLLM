# InternVL：把视觉编码器放大，再逐段和语言模型对齐

- 论文：InternVL: Scaling up Vision Foundation Models and Aligning for Generic Visual-Linguistic Tasks
- 作者：陈喆等（上海人工智能实验室 OpenGVLab、南京大学、香港大学、香港中文大学、清华大学、中国科学技术大学、商汤）
- 发表：CVPR 2024（口头报告）
- 预印本：arXiv:2312.14238
- 对应 PDF：`2024-CVPR-InternVL.pdf`
- 阅读顺序：本目录第 5 篇，也是这组材料的最后一篇。

## 先读这一段

到 LLaVA 为止，开源多模态模型的眼睛大多还是 CLIP 时代的 ViT，参数量远小于后面的语言模型，中间只靠一个随机初始化的小桥。InternVL 认为这条路浪费了语言模型的容量：视觉特征又弱，表示空间又和语言模型不一致，小桥也装不下复杂的跨模态关系。

这篇把视觉编码器做到约 60 亿参数（InternViT-6B），再用一个从多语言 LLaMA 初始化的中间件 QLLaMA 去做对齐，而不是只靠 Q-Former 或一个线性层。CVPR 2024 口头报告。它是这五篇里唯一把“视觉基础模型本身太小”当成主问题的一篇。

## 它在解决什么

语言模型已经往千亿参数走，接到它们上面的视觉编码器仍常在十亿上下。这些编码器要么在纯视觉数据上预训练，要么像 CLIP 那样对齐到 BERT 风格的文本塔，和 LLaMA 这类解码器不是同一个表示空间。网页图文又多又脏，直接拿来做生成式训练不稳定。作者要一条能同时覆盖感知、检索、描述和对话的训练路线，并且尽量只用公开数据。

## 核心做法

两个大部件。

- InternViT-6B：普通 ViT，约 59 亿参数，宽度 3200、深度 48。结构是在 LAION 英文子集上用对比学习做小规模搜索后定下来的。图像编码器在第一段是随机初始化，不是从 CLIP 权重复用。这是和 LLaVA 的一个实质差别。
- QLLaMA：约 80 亿参数的语言中间件，用多语言 LLaMA-7B 初始化，再加入 96 个可学习 query 和随机初始化的交叉注意力（大约 10 亿参数）。它有两个身份：对比学习时的文本塔，以及把视觉 token 整理成语言模型能接的前缀。作者强调它比 Q-Former 大约大 42 倍。

训练三段，数据从脏到净。

1. 对比预训练。InternViT-6B 和多语言 LLaMA 全部可训，损失就是 CLIP 的对称交叉熵。公开图文对原始约 60.3 亿，清洗后约 49.8 亿，含英文、中文和多语言。这一段使模型能做零样本分类和图文检索，视觉编码器也能单独拿去线性探测。
2. 生成式预训练。InternViT 和 QLLaMA 的原有权重冻住，只训新的 query 和交叉注意力。数据再滤到约 10.3 亿、描述质量更高的样本。损失沿用 BLIP-2 的三项：对比、匹配、看图生成文字。
3. 监督微调，得到 InternVL-Chat。接到现成的 Vicuna 或 InternLM，中间是一个 MLP。指令数据大约 400 万条，包括描述、各类 VQA、OCR、定位和 LLaVA 那类对话。有两种接法：只用 InternViT-6B，类似 LLaVA-1.5；或者 ViT 加 QLLaMA 一起上。因为 QLLaMA 已经靠近语言模型的空间，有的设置里可以冻住解码器，只训 MLP。

用法被作者比成瑞士军刀。感知任务只用 InternViT；检索可以走 InternVL-C（视觉塔）或 InternVL-G（视觉塔加 QLLaMA 的 query）；描述由 QLLaMA 自己生成；对话再外接一个解码器。

论文报告的范围因此很宽：ImageNet 线性探测、ADE20K 分割、Kinetics 视频分类、Flickr30K 和 COCO 检索、图像描述，以及 MME、POPE 等对话评测。线性探测上，InternViT-6B 在不使用私有 JFT 数据的模型里处于当时前列，并在多个设定下强于更大的 ViT-22B。

## 读的时候抓住什么

1. 图 1。三种范式放在一起：分类监督的视觉模型、CLIP 式双塔、InternVL 的“大视觉编码器 + 与 LLM 对齐”。这张图就是全文论点。
2. 引言里的三条限制：参数量不配、表示空间不一致、连接层太薄。后面的设计是逐条回应，不是堆模块。
3. 图 3 的三段。对比学习吃大规模脏数据，生成学习吃滤过的数据，监督微调才上对话。数据日程和模块同样重要。
4. 第 3.2 节 QLLaMA 相对 Q-Former 和线性层的三点对比。这是它和 BLIP-2、LLaVA 的分界。

感知实验（分类、分割）值得扫一眼，因为作者要证明放大的是视觉能力，不只是对话分数。对话表格不用逐行背。

## 可以先跳过

- InternViT 深度、头维度、MLP 比例的搜索过程。知道他们在速度、精度、稳定性之间选了一个 48 层的配置即可。
- 32 个榜的完整数字。图 2 的覆盖范围比单个百分数更有信息量。
- 和后续 InternVL 1.5、InternVL2 的实现差异。那些是系列后的工程演进，不是这篇论文的论点。

## 读完应留下的判断

这五篇走到这里，多模态模型不再是“一个 CLIP，加一个桥，加一个聊天语言模型”的唯一形态。视觉侧可以单独成为基础模型，对齐要分阶段，连接层也可以大到本身就是一个语言模型。

代价是训练重，QLLaMA 这个中间件后来并没有成为所有实验室的标配。很多后续系统仍用 LLaVA 式的简单投影，但会换上更强、分辨率更灵活的视觉编码器。InternVL 留下的是问题定义：眼睛不够大、和语言模型不对齐时，后面的指令微调补不回来。

## 和前面四篇怎么串

CLIP 给出图文对比学习，InternVL 第一段仍在用它，只是视觉塔从零放大到 60 亿。Flamingo 给出“冻结的语言模型 + 交叉注意力注入视觉”。BLIP-2 把注入收成 query 瓶颈，并留下对比、匹配、生成三项损失；InternVL 第二段直接沿用这三项。LLaVA 给出指令微调和线性 / MLP 投影；InternVL 第三段的对话数据和对接方式沿这条线，同时允许把投影前面换成已经对齐过的大视觉模型。
