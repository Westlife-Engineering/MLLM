# Flamingo：把冻结的大语言模型变成能看图的少样本模型

- 论文：Flamingo: a Visual Language Model for Few-Shot Learning
- 作者：Jean-Baptiste Alayrac 等，DeepMind
- 发表：NeurIPS 2022
- 预印本：arXiv:2204.14198
- 对应 PDF：`2022-NeurIPS-Flamingo.pdf`
- 阅读顺序：本目录第 2 篇。先读 CLIP。

## 先读这一段

CLIP 解决的是“图和文在同一个空间里靠近”。Flamingo 解决的是下一句：已经有一个很强的纯文本大语言模型，怎样让它在几乎不改动原有能力的前提下，根据图像或视频把字生成出来，并且像 GPT-3 那样，提示里给几个例子就能换任务。

这是“视觉语言模型”（VLM）这个词在大模型时代被用开的起点。权重没有公开，但结构后来被 OpenFlamingo 等复现，也直接被 BLIP-2、LLaVA 拿来当对照。

## 它在解决什么

当时的图文模型多半是一个任务一个输出头：检索、描述、视觉问答分开训。大语言模型已经证明，很多语言任务可以收成“给几个示例，然后续写”。视觉这边还做不到同等的少样本适应，因为模型要么看不到图，要么看见图之后必须为每个数据集更新权重。

Flamingo 要求：图、视频和文字可以交错出现；输出是自由文本；换任务时不更新参数，只在提示里放若干输入输出示例。

## 核心做法

三块拼在一起。视觉编码器和语言模型都尽量沿用已经训好的模型，中间只训练新加的部分。

1. 视觉编码器。冻结的 NFNet-F6。它自己先用图文对比损失预训练，损失形式来自 CLIP。视频按每秒 1 帧各自编码，再加上时间位置编码。编码器输出的是一块空间特征，不是一个单独向量。
2. Perceiver Resampler。视觉特征的数量随分辨率和帧数变化，直接送进语言模型太贵。用固定的 64 个可学习 query，通过交叉注意力去读这些特征，压成 64 个视觉 token。消融里它优于普通 Transformer 和 MLP。
3. 门控交叉注意力。在冻结的语言模型层之间插入新的层：语言隐状态做 query，视觉 token 做 key 和 value，后面再跟一个前馈层。新层输出乘上 tanh(α)，α 初始化为 0。因此训练刚开始时，这些层的贡献是 0，模型行为和原来的语言模型一致，然后再慢慢打开视觉条件。

语言模型用的是 Chinchilla，规模 1.4B、7B、70B，对应 Flamingo-3B、9B、80B。变大的是语言模型和那些新插入的层；视觉编码器和 Perceiver 的大小保持不动。论文里说的 Flamingo 默认指 80B。

训练数据是网页上的图文，不是为某个榜单标的。关键一份是 M3W：从大约 4300 万个网页的 HTML 里，按页面结构把图片插回文字中间。训练时一条序列最多 5 张图，但交叉注意力被做成“每个文字 token 只直接看它前面最近的那一张图”，更早的图靠语言模型自己的自注意力传递。所以评估时可以把示例加到 32 个，不必和训练时的图片数相同。

任务适应就是少样本提示。支持集里放若干“图 + 标准答案”，再放查询图，让模型续写。16 个图文或视频任务里，有 5 个被拿来调设计，另外 11 个留作没调过的估计。32 个示例、不更新权重的情况下，在其中 6 个任务上超过了当时用大量标注微调的最好结果。

## 读的时候抓住什么

1. 图 3 的整体结构和图 4 的门控交叉注意力。这是全文的方法。
2. 交错序列和“只看最近一张图”的掩码。这解释了少样本为什么成立：训练分布里本来就有“图、文、图、文”这种上下文。
3. 图 2 右侧：性能随模型变大和示例变多而上升。这是他们想证明的规模现象。
4. 消融（第 3.3 节）：门控、Perceiver、交错数据，各自去掉会怎样。第一遍看结论即可。

论文很长，附录里有大量提示格式和单任务数字。那些是在证明“一个模型覆盖很多任务”，不是另一套方法。

## 可以先跳过

- NFNet 对比模型本身的检索数字（附录）。
- 每个榜单的支持集怎么切。知道他们把开发集和留出集分开，是为了避免拿测试集调结构，就够了。
- 微调实验（第 3.2 节）说明权重也能继续训，但论文的主张是少样本、不微调。

## 读完应留下的判断

Flamingo 把多模态模型定义成“一个会生成文字的模型，视觉是条件”。少样本靠的是交错的网页数据，不是后来那种指令对话数据。

它贵，而且闭源。视觉注入的方式是往大语言模型内部插入很多新层，训练和实现都重。下一篇要回答的就是：能不能把两边都冻住，只训一个小模块。

## 和下一篇的关系

BLIP-2 接受 Flamingo 的目标（冻结的强语言模型 + 开放式图文生成），但拒绝它的代价。Q-Former 用几十个 query 把视觉压成语言模型读得懂的前缀，可训练参数量小一个数量级以上。
